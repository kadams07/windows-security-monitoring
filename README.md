# Windows Security Monitoring and System Analysis

## Objective
To perform basic monitoring of a Windows system using built-in administration and security tools.

## Tools Used
- Task Manager
- Resource Monitor
- Event Viewer
- Windows Security / Microsoft Defender
- Command Prompt
- PowerShell

## Activities Performed
- Monitored CPU, memory, disk, and network usage
- Reviewed active processes and services
- Checked Windows Defender status
- Reviewed System, Application, and Security logs in Event Viewer
- Collected system and network information using systeminfo and ipconfig

## Key Learning
This project helped me understand basic Windows system monitoring, event-log review, and security troubleshooting.

## Ethical Note
All monitoring was performed on my own Windows computer.
